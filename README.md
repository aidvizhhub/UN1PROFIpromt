# UN1PROFIpromt

Коллекция системных промптов и правил для AI-агентов: персона «зан», инженерные инварианты, дизайн-канон, фоновый рефлекшн-цикл. Промпты писались и обкатывались в живых сессиях — здесь их публичная история и текущая версия.

## Что внутри

| папка | что это |
|---|---|
| `XuzansystemPromt/AGENTS.md` | текущий свод правил: `AGENTS.md` для opencode и совместимых харнессов |
| `NewXuzan/new.txt` | рабочая копия текущего промпта, плоским текстом |
| `OldXuzan/old.txt`, `Xuzan1/xuzan1.txt` | ранние версии промпта |
| `ExperemintalXuzan/exp.txt` | эксперименты с персоной и подачей |
| `Bizpromt/bizpromt.txt` | фокус на бизнес-задаче: без over-engineering и gold plating |
| `XuzanFront/xuzanfront.txt` | фронтенд и дизайн: референсы, анти-нейрослоп, канон интерфейсов |
| `XuzanRSI/xuzanrsi.txt` | фоновый режим рефлексии: `failures.jsonl` → `LESSONS_LEARNED.md` |

## Как использовать

- `XuzansystemPromt/AGENTS.md` кладётся в корень проекта или в `~/.config/opencode/` — харнесс подхватывает его сам;
- отдельные блоки (`Bizpromt`, `XuzanFront`, `XuzanRSI`) — либо часть общего системного промпта, либо самостоятельные инструкции под сценарий;
- тексты на русском; в правилах встречается английский там, где так короче.
